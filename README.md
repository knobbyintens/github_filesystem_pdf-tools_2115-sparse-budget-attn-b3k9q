# Budgeted Sparse Attention - Official Code

Official implementation released by the authors of **Budgeted Sparse Attention**
(NeurIPS 2025, arXiv:2511.07731).

Budgeted Sparse Attention learns a per-head sparsity budget and applies a
block-sparse mask to the attention matrix. This repository contains the training
and evaluation code accompanying the paper.
